## 待确认 Gate

这些不是“以后再说的小优化”；相应工程开始前必须有结论。

| Gate | 为什么阻塞 | 推荐默认值 | 负责人 / 时点 |
| --- | --- | --- | --- |
| Glass 字幕结构 | 双框会增加同步、滚动、长句裁切与更新跳动的状态空间。 | 一个字幕卡：英文在上、中文在下；Compact Overlay 只保留当前翻译。以两个可点击原型再确认。 | 原生展示 UI Issue。 |
| 月度包含额度与超额策略 | 没有 Token/分钟上限，就无法保证 A$15 订阅的单位经济。 | Beta 测得每小时成本后，选择“每月含 X 活跃翻译分钟；耗尽后本地草稿可继续、云端 Final 停止或购买附加额度”。 | 私测数据收集后、StoreKit 配置前。 |
| 云端主/备模型 | 延迟、质量、地区可用性与单位成本共同决定体验。 | 一个正式主模型 + 一个服务端 fallback；不把多 Provider 池暴露给客户端。 | Cloud 端到端压测后。 |
| 提供 3 小时体验的公开形式 | 受邀邀请码适合 Beta；公开 App Store 的体验权益需要符合最终 IAP 呈现方式。 | Beta 使用邀请码；公开版先提供免费有限云端服务或合规的 StoreKit 试用/订阅方案，提交审核前复核。 | App Store Connect 配置前。 |

## MVP 明确不做

- 多 ASR 选择器、Parakeet/MLX 商店功能承诺。
- 普通用户可见的 Provider、模型、temperature、VAD、Prompt、Token 单价等开发参数。
- 云端原始音频存储、跨设备 transcript 同步、Ask your transcripts。
- PDF/PPT 自动整份上传；仅保留本地提取、术语候选和用户确认。
- iPhone/iPad App、网页端、团队工作区、多说话人归因。
- 任何把供应商 API Key 放进客户端、配置文件、安装包或日志的做法。
